# Proje Durum Raporu: AI Club Site

## 🚀 Genel Durum
Proje, modern bir "Cyberpunk/Quantum" estetiğiyle tasarlanmış, tek sayfalık bir landing page olarak geliştirilmiştir. Mevcut yapı, yüksek performanslı Tailwind CSS ve minimal JavaScript etkileşimleri üzerine kuruludur.

## 🛠 Teknik Detaylar
- **Teknoloji Yığını:** HTML5, Tailwind CSS, Vanilla JavaScript.
- **Tasarım Teması:** Koyu arka plan (`#020617`), neon gradyanlar, cam efektleri (Glassmorphism).
- **Kritik Özellikler:**
    - İnteraktif parçacık sistemi (Particle Canvas).
    - Dinamik fare imleci takibi.
    - Scroll-reveal animasyonları.
    - SEO uyumlu JSON-LD yapısal veri entegrasyonu.

## 📝 Son Güncellemeler
- **Üyelik Butonu Entegrasyonu:** "Kulübe Katıl" butonu, özel neon tasarım ve animasyonlarla birlikte Hero Section'a eklenmiştir.
- **Link Güncellemesi:** Üyelik butonu resmi üniversite kulüp portalına (`https://kulupler.hitit.edu.tr/`) yönlendirilmiştir.

## ☁️ Deployment & CI/CD
- **Platform:** Vercel.
- **Entegrasyon:** GitHub repository bağlantısı kurulmuştur.
- **Akış:** GitHub'a yapılacak her `push` işlemi, Vercel tarafından otomatik olarak algılanacak ve canlıya alınacaktır (Continuous Deployment).
